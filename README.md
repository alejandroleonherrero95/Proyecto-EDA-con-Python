Este proyecto consiste en un análisis exploratorio de datos (EDA) realizado con Python.
Se han trabajado dos fuentes principales de información: un fichero CSV con datos de campañas de marketing y un Excel con detalles de clientes.

El flujo seguido fue:

Preparación de los datos (src/prepare_data.py), incluyendo limpieza de duplicados, transformación de variables y unión de ambos datasets.

Generación de un conjunto de datos procesados en la carpeta data/processed/.

Análisis exploratorio en un notebook (notebooks/01_EDA.ipynb), donde se incluyen estadísticas descriptivas, gráficos de distribución, correlaciones y algunos ejemplos de análisis bivariado.

El objetivo es comprender mejor las características de los clientes y las campañas, identificando patrones relevantes que puedan servir de apoyo a la toma de decisiones.
